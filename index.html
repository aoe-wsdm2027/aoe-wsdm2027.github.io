About the Workshop

E-commerce AI is moving from static prediction pipelines toward closed-loop systems in which agents interpret goals, use tools, retain experience, conduct experiments, and adapt decisions over time.

AOE brings these directions into one workshop. We study agents that assist shoppers and businesses, agents that improve models and pipelines, and interactive environments that reveal how each action changes what happens next.
